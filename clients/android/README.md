# clients/android — FuseOS Android app

Kotlin + Jetpack Compose. Clipboard capture/injection (`ClipboardManager`), LAN peer discovery (NSD/mDNS), a foreground service for the persistent data-plane connection, and file send/receive via the Storage Access Framework.

Built with Gradle (`./gradlew assembleDebug`), **outside** the PNPM workspace. Generates protobuf bindings from [`../../proto/`](../../proto/).

Status: scaffold.
