# clients/macos — FuseOS macOS app

SwiftUI. Clipboard capture/injection (`NSPasteboard`), LAN peer discovery (Bonjour / `Network.framework`), the persistent data-plane connection, and a Share extension ("Send to my phone").

Built with Xcode / `xcodebuild`, **outside** the PNPM workspace. Generates protobuf bindings from [`../../proto/`](../../proto/).

Status: scaffold.
